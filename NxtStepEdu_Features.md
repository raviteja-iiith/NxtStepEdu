# NxtStepEdu — School ERP Platform

### Empowering Schools with Smart, Role-Based Management

NxtStepEdu is a comprehensive, cloud-based School ERP designed to simplify and digitize every aspect of school administration. Built for **Principals**, **Teachers**, and **Parents**, it provides a unified platform where each stakeholder gets a personalized portal with features tailored to their exact needs.

---

## 🏫 Principal Portal

> *"Complete school control — from academics to finance — all in one dashboard."*

The Principal Portal is the command center of the entire school. It gives school leaders full visibility and control over academics, staff, students, finances, and communications.

### Key Features

| Feature | Description | Benefit |
|---------|-------------|---------|
| **📊 Real-Time Dashboard** | Live stats for total students, staff count, today's attendance %, and pending fee deficit — updated in real time. | Instant school health overview without digging through reports. |
| **🏠 Class & Section Management** | Create, edit, and delete classes and sections. Assign class teachers to sections. Supports multiple academic years. | Organize the entire academic structure in minutes. |
| **📚 Subject Management** | Add subjects per class with per-section teacher assignments. Configure periods/week for each subject. | Flexible curriculum setup — assign different teachers to different sections of the same subject. |
| **🗓️ Automated Timetable Generator** | AI-powered timetable builder with conflict detection, priority subject support, and cross-section teacher clash prevention. Manual editing also supported. | Eliminates hours of manual scheduling. Handles complex constraints automatically. |
| **👩‍🏫 Teacher Management** | Add teachers individually with auto-generated credentials (username + password). Assign subjects, sections, and class teacher roles. Activate/deactivate accounts. | Centralized staff directory with secure, system-generated login credentials. |
| **👨‍🎓 Student Management** | Admit students individually or via bulk Excel import. Edit profiles, transfer between classes/sections, track admission history. | Handles 1 to 1000+ students with equal ease. Bulk import saves days of manual entry. |
| **👨‍👩‍👧 Parent Management** | Bulk import parents from Excel template. Auto-generate PINs. Link parents to students with relationship tracking. | Parents get instant access — credentials auto-downloaded as an Excel file for distribution. |
| **📋 Attendance Overview** | View school-wide attendance percentage for the day. Identify sections where attendance hasn't been marked. | Spot absenteeism trends and ensure every class is tracked daily. |
| **💰 Fee Management** | Create fee structures, track payments, generate fee reminders. View school-wide fee deficit (actual unpaid balance after partial payments). | Accurate financial tracking — no more guessing how much is owed. |
| **📝 Exam Management** | Create exams, assign to sections, publish schedules. | Centralized exam planning visible to teachers and parents. |
| **📊 Marks & Results** | View marks entered by teachers. Generate class-wide result analytics. | Data-driven academic performance insights at a glance. |
| **📢 Broadcast Announcements** | Send announcements to all, teachers only, or parents only. Mark as urgent for priority visibility. Auto-creates in-app notifications for all recipients. | Instant school-wide communication — no more circular distribution. |
| **📄 Report Generation** | Generate and print/PDF school dashboard reports including stats, pending leaves, and recent announcements. | Professional reports ready for board meetings or parent-teacher conferences. |
| **🔐 Credential Reset Management** | View and resolve password/PIN reset requests from teachers and parents. Generate new credentials securely. | No more manual password resets via email — everything handled in-portal. |
| **📅 Academic Year Management** | Create and switch between academic years. View archived data in read-only mode. Promote classes across years. | Seamless year-end transitions without data loss. |
| **🔔 Real-Time Notifications** | In-app notification bell with unread count, mark-as-read, and notification history. | Stay on top of every school event without checking each page. |
| **📱 Mobile Responsive** | Fully responsive layout with collapsible sidebar, hamburger menu, and optimized mobile views. | Manage your school from anywhere — phone, tablet, or desktop. |

### How It Benefits Principals

- **Save 10+ hours/week** on administrative tasks like scheduling, fee tracking, and credential management
- **Zero paperwork** — everything from admissions to announcements is digital
- **Real-time visibility** — no waiting for end-of-day reports; see attendance, fees, and activity live
- **Secure by design** — role-based access ensures teachers and parents only see what they should

> *"Focus on teaching — let the system handle the paperwork."*

The Teacher Portal is designed to minimize administrative burden while maximizing classroom effectiveness. It adapts based on whether the teacher is a **Class Teacher** or a **Subject Teacher**.

### Key Features

| Feature | Description | Benefit |
|---------|-------------|---------|
| **📊 Personalized Dashboard** | Welcome banner with greeting, quick stats, and pending actions relevant to the teacher's assigned classes. | Start every day knowing exactly what needs attention. |
| **📋 Attendance Marking** *(Class Teachers)* | Mark daily attendance for assigned section — Present, Absent, Late, or Excused. Bulk mark all present with one click. | Takes under 2 minutes to complete daily attendance for an entire class. |
| **📝 Marks Entry** | Enter exam marks for assigned subjects and sections. View student-wise and subject-wise breakdowns. | Direct mark entry without paper forms or Excel sheets. |
| **📚 Assignments** | Create and manage assignments for classes. Track submission status. | Digitize homework and assignment tracking. |
| **👨‍🎓 My Students** | View list of all students in assigned sections/subjects. Access student profiles, academic history, and attendance records. | Know your students — their performance, attendance, and background — all in one place. |
| **👨‍👩‍👧 Parent Directory** *(Class Teachers)* | View parent contact details for students in assigned class. See linked student information. | Reach out to parents instantly when needed. |
| **🔐 PIN Reset Requests** | View and resolve parent PIN reset requests for linked students. Generate new PINs securely. | Help parents regain access without involving the principal. |
| **📖 Lesson Plans** | Create and organize lesson plans by subject and date. | Plan ahead and maintain teaching continuity. |
| **📁 Resources** | Upload and manage teaching resources for classes. | Build a digital resource library accessible anytime. |
| **💬 Messages** | Communicate with parents and other staff through the in-app messaging system. | Direct, trackable communication — no lost messages. |
| **🏖️ Leave Management** | Apply for leave with type, date range, and reason. Track approval status. | Transparent leave application process with audit trail. |
| **🔔 Notifications** | Receive notifications for announcements, leave approvals, and other school events. | Never miss an important update from the school administration. |
| **🔒 Change Password** | Securely change password from within the portal. Password strength indicator included. | Maintain account security with ease. |
| **🏫 Role-Based Access** | Class Teachers see attendance and parent modules; Subject Teachers see only their relevant sections. URL-level guards prevent unauthorized access. | Clean, uncluttered interface — see only what you need. |

### How It Benefits Teachers

- **2-minute attendance** — mark an entire class present/absent in under 2 minutes
- **No duplicate work** — marks entered once flow to principal's dashboard and parent's portal automatically
- **Class vs. Subject teacher distinction** — Subject teachers aren't overwhelmed with attendance and parent modules they don't need
- **Secure credential management** — first-login password change enforced, with strength requirements

## 🔐 Security & Administration (Cross-Cutting)

These features apply across all portals:

| Feature | Description |
|---------|-------------|
| **Role-Based Access Control (RBAC)** | Middleware enforces that principals can only access `/principal/*`, teachers only `/teacher/*`, and parents only `/parent/*`. URL manipulation is blocked. |
| **First-Login Password/PIN Change** | Every new user (teacher, parent, principal) is forced to change their auto-generated credential on first login before accessing any portal features. |
| **Account Activation/Deactivation** | Deactivated accounts are automatically signed out and blocked from logging in with a clear error message. |
| **School Pause Protection** | If a school's subscription is paused, all its users (except admin) are signed out and blocked. |
| **Secure Credential Generation** | Passwords are generated with alphanumeric characters (excluding ambiguous ones like 0/O, 1/l). PINs are 6-digit random numbers. |
| **Admin Rollback on Failure** | If user record creation fails after auth account creation, the auth account is automatically deleted (rollback). |
| **Cross-School Isolation** | All data queries include `school_id` filters. One school's data is never visible to another school's users. |
| **Audit Trail** | Credential resets track who resolved them and when. Leave requests maintain full approval history. |
